# 调式侦测 · MIDI Mode Finder

一个纯前端的 MIDI 调式识别工具。上传 `.mid` / `.midi` 文件后，应用会在浏览器本地读取音符、时值、力度、速度、拍号与调号信息，并在「自然大调」与「和声小调」之间给出候选排序。

## 使用方式

直接打开 `index.html` 即可使用。若浏览器限制了本地文件脚本，也可以在当前目录启动一个静态服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

左侧可以提前提供调性类别和主音，未确定时保持「自动判断」与「自动」。右侧结果会展示置信度、十二音级能量、候选排序和三条判断依据。内置示例可用来快速体验完整流程。

## 识别说明

识别使用加权音级轮廓作为主依据，并结合结尾主音重心、属音支撑、最后音符以及和声小调中的升高第七级（导音）解决倾向。它适合旋律和常规多轨 MIDI 的快速分析；转调频繁、片段很短或终止不完整时，应结合候选排序与乐谱/听感复核。
